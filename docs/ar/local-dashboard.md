# لوحة المراقبة المحلية بـ FastAPI

هذه اللوحة هي موقع الويب الوحيد في التصميم الحالي. تعمل محليا، وتتصل
مباشرة بقاعدة PostgreSQL الفعلية لعرض سجلات المفاتيح وتعديل حالة الخدمة.

## التشغيل

```powershell
cd .\services\cloud-api
Copy-Item .\.env.example .\.env
# حرر .env وضع بيانات PostgreSQL.
python .\app.py --init-db-only
python .\fastapi_app.py
```

افتح:

```text
http://127.0.0.1:8080/
```

## معنى الحالة

| القيمة | الأثر على خدمة Rust |
| --- | --- |
| `1` | يسمح بالتثبيت الجديد، ويعيد تمكين التوليد عند وصول القيمة للخدمة |
| `0` | يمنع التثبيت الجديد، وتوقف الخدمة المثبتة التوليد عند وصول القيمة إليها |

السجلات المعلقة قبل الإيقاف تستمر في الرفع إلى PostgreSQL، حتى لا تضيع
معلومات المفاتيح التي سبق إنشاؤها.

## المسارات

| المسار | الوظيفة |
| --- | --- |
| `GET /` | صفحة العرض والتحكم |
| `GET /health` | التحقق من تشغيل اللوحة |
| `GET /api/status` | قراءة الحالة |
| `PUT /api/status` | كتابة `{"status":"0"}` أو `{"status":"1"}` |
| `GET /api/activation-logs?limit=100` | قراءة أحدث السجلات المرفوعة |

## الحماية

تستمع اللوحة افتراضيا على `127.0.0.1` وترفض الطلبات غير المحلية. لا تغير
`ADMIN_WEB_ALLOW_REMOTE=1` إلا بعد إضافة مصادقة وحماية شبكة مناسبة.
