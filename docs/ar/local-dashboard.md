# لوحة الإدارة المحلية بـ FastAPI

## الدور

لوحة FastAPI هي موقع إدارة محلي فقط. تستخدم لمهمتين:

- عرض السجلات التي وصلت إلى جدول PostgreSQL `activation_logs`.
- حذف سجل مفتاح واحد عند الحاجة، بعد تأكيدين من صفحة الويب.
- تغيير قيمة `server_control.status` بين `1` و`0`.

لا تتوسط اللوحة بين واجهة المولد والخدمة، ولا يجب نشرها كخدمة عامة.

## التشغيل

```powershell
cd .\services\local-dashboard
python -m pip install -r .\requirements.txt
Copy-Item .\.env.example .\.env
# ضع بيانات PostgreSQL التي تستطيع قراءة السجلات وتعديل الحالة.
python .\app.py --init-db-only
python .\fastapi_app.py
```

افتح في نفس الجهاز:

```text
http://127.0.0.1:8080/
```

الإعداد الافتراضي يربط الموقع بالعنوان المحلي ويرفض الطلبات القادمة من
أجهزة أخرى.

## الصفحة الرئيسية

تعرض الصفحة:

- الحالة الحالية `0` أو `1`.
- زر أو إجراء لتغيير الحالة.
- أحدث سجلات المفاتيح التي وصلت فعلا إلى PostgreSQL.
- اختيار عدد الصفوف الظاهرة.
- زر `حذف` لكل سجل، ولا ينفذ إلا بعد قبول تأكيدين متتاليين.

السجل الذي ما زال في `pending_uploads.json` على جهاز المولد لن يظهر في
اللوحة حتى تنجح عملية رفعه.

الحذف يزيل السجل من PostgreSQL فقط. إذا كان جهاز مولد ما زال يحتفظ بالعملية
في طابور مزامنة غير مؤكد، فمن الممكن أن يعيد رفعها لاحقا.

## معنى الحالة

| القيمة | أثرها |
| --- | --- |
| `1` | يسمح بتثبيت جهاز جديد، ويمكّن التوليد في خدمة استلمت هذه القيمة |
| `0` | يرفض تثبيت جديد، وتوقف الخدمة التوليد بعد استلامها القيمة |

ملاحظات مهمة:

- تغيير الحالة لا يقتل خدمة Windows؛ بل يمنع توليد مفاتيح جديدة.
- تستمر الخدمة في محاولة رفع السجلات التي أُنشئت سابقا.
- جهاز مفصول عن الإنترنت لا يستلم التغيير إلى `0` حتى يعيد الاتصال.

## مسارات HTTP

| المسار | الوظيفة |
| --- | --- |
| `GET /` | الصفحة الرسومية المحلية |
| `GET /health` | التحقق من تشغيل موقع الإدارة |
| `GET /api/status` | قراءة حالة التشغيل |
| `PUT /api/status` | كتابة `{"status":"0"}` أو `{"status":"1"}` |
| `GET /api/activation-logs?limit=100` | قراءة آخر السجلات المرفوعة |
| `DELETE /api/activation-logs/{id}` | حذف سجل واحد؛ تستدعيه الصفحة بعد تأكيدين |

مثال تغيير الحالة من PowerShell على جهاز الإدارة:

```powershell
Invoke-RestMethod -Uri http://127.0.0.1:8080/api/status `
  -Method Put -ContentType application/json -Body '{"status":"0"}'
```

## تهيئة أو تفريغ السجلات

أمر `python .\app.py --init-db-only` ينشئ البنية اللازمة ولا يحذف السجلات.

لحذف سجل مفرد استخدم زر `حذف` في صفه. يظهر تأكيد أول لاختيار السجل، ثم
تأكيد نهائي ينبه إلى أن العملية غير قابلة للتراجع.

إذا احتجت بدء سجل جديد، يجب تنفيذ حذف واع بقاعدة البيانات والتأكد أولا من
عدم وجود `pending_uploads.json` على أي جهاز مولد؛ وإلا قد تعود سجلات قديمة
بعد الحذف. لا تحذف `server_control` عند تفريغ سجل المفاتيح.

## الحماية

- اترك `ADMIN_WEB_HOST=127.0.0.1`.
- لا تضبط `ADMIN_WEB_ALLOW_REMOTE=1` دون إضافة مصادقة وجدار ناري وتشفير.
- استخدم حساب إدارة خاصا للوحة ولا تشارك ملف `.env`.
- امنح حساب اللوحة `DELETE` على `activation_logs` فقط إذا أردت استعمال زر الحذف.
- لوحة الإدارة قادرة على تغيير حالة التشغيل، لذلك تعامل مع جهازها كجهاز
  إداري حساس.
