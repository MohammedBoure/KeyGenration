## خريطة سريعة

```text
ActivateurRMS.exe  -->  KeyGenService.exe/NSSM  -->  PostgreSQL
                               ^
                               | HTTP محلي فقط

FastAPI محلي على جهاز الإدارة  ----------------->  PostgreSQL
```

الخادم البعيد يخزن بيانات PostgreSQL فقط. توليد المفاتيح يتم في خدمة Rust
المحلية، وتعرض لوحة FastAPI السجلات وتغير حالة التشغيل من جهاز الإدارة.
